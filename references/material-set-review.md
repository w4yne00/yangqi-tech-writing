# 材料集追溯与冲突阻断

材料集联审用于检查同一工程、课题或治理事项中，上游依据、设计落实、采购承诺、实施记录和验收证据之间的可追溯关系。它只判断输入是否足以进入联审，以及关系和冲突是否需要人工确认；不代替审批、合同解释、法律效力判断或技术正确性裁决。

## 输入合同

最高层感知请求可以增加 `material_set`：

- `set_id`：材料集标识；
- `upstream_materials_complete`：用户是否确认联审所需上游材料已提供；
- `materials`：每份材料记录 `material_id`、标题、版本、材料子类型和状态；`status` 只接受 `draft`、`approved`、`signed`、`effective`、`superseded` 或 `unknown`，日期可选，用户明确指定控制性材料时使用 `user_designated_control: true`；
- `relations`：每项记录关系标识、起点材料、终点材料、关系类型和明确依据；
- `conflicts`：每项记录冲突材料、冲突维度、差异、影响和待确认项；用于说明某条 `conflicts_with` 时，以 `relation_id` 引用该关系，且两侧材料必须一致。

材料关系只接受以下七类：

| 关系 | 含义 |
|---|---|
| `governs` | 一份已确认控制性材料约束另一份材料 |
| `derives_from` | 当前材料的要求或结论可追溯到上游来源 |
| `supersedes` | 有明确变更或替代依据的新材料替代旧材料 |
| `implements` | 实施、设计或承诺项落实上游要求 |
| `verifies` | 证据或审查结论验证被检查事项 |
| `conflicts_with` | 两份材料存在不能同时成立的正式口径 |
| `unclear` | 已知材料相关，但控制、派生或落实关系不明 |

关系必须由用户输入或正式来源明确给出。文件日期较新、版本号较大、篇幅更完整或标题更正式，都不能自动形成 `supersedes`、`governs` 或其他优先级关系。

材料集中有两份及以上材料时，每份材料必须至少参与一条指向另一份材料的跨材料关系。部分材料孤立、仅存在自关联或关系数组为空，都表示关系不明并形成待确认和阻断项；自关联 `governs` 不进入控制依据。

## 控制性材料

以下明确依据可以进入感知决策：

- 材料状态为 `approved`，表示输入明确声明已批准；
- 材料状态为 `signed`，表示输入明确声明已签署；
- 用户指定该材料为控制性材料；
- 输入以 `governs` 明确声明控制关系。

这些依据只说明当前联审采用的控制线索，不自动证明法规适用、合同解释或法律效力。多个控制线索相互冲突时仍须阻断，不按日期自行选取胜者。

## 冲突合同

正式口径冲突至少覆盖范围、数量、参数、责任、时间、结论和陈述效力。每个冲突项只呈现：

1. 涉及的材料；
2. 不能同时成立的差异；
3. 对写作、落实或验证的影响；
4. 需要用户或正式流程确认的事项。

输出不得增加“最终采用”“自动覆盖”“法律效力更高”等裁决字段。`conflicts_with`、`unclear` 以及结构化冲突项都会形成阻断；未经确认不得自动定稿。

每条 `conflicts_with` 都按自身 `relation_id` 与结构化冲突逐项关联；同一材料对的另一条冲突不能代替该关系的明细。仅声明 `conflicts_with` 而没有对应结构化冲突时，输出仍形成可审查的未完整冲突项：`basis` 作为当前差异，`dimension` 标为 `unclear`，`impact` 标为 `not_provided`，待确认项标为 `provide_conflict_dimension_and_impact`。这些值明确表示输入缺口，不是系统推断的冲突影响。

## 单材料和上游缺失

没有 `material_set` 时，当前任务按单材料模式处理。单材料内部检查可以继续，但输出必须明确“无法验证跨阶段一致性”，并将联审完成状态保持为 `not_completed`，不能包装成材料集联审完成。

提供了 `material_set` 但 `upstream_materials_complete` 为 `false` 时，增加 `material_set:missing_upstream` 阻断项。即使完整性声明为 `true`，材料集中只有一份材料时仍以 `material_set:insufficient_materials` 阻断跨阶段联审。只有用户声明上游材料完整、至少提供两份材料、关系明确且没有未解决冲突时，输入才进入 `reviewable`；该状态只表示可开展联审，不表示联审已经完成或材料已经一致。

## 输出边界

`material_set_review` 输出材料关系、控制依据、冲突、跨阶段可核验状态和完成声明。关系不明、上游缺失或正式口径冲突时，处理模式保持保守并等待确认。系统只呈现差异、影响和待确认项，不替用户作审批、合同、技术或法律效力裁决。
