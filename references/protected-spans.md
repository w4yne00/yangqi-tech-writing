# 保护片段

## 目的

风格改写不得破坏事实、术语、责任和正式结论。先标记保护片段，再扫描 AI 痕迹；保护规则的优先级高于词表和句式规则。

## 默认保护范围

- 法律法规、政策名称、政策文号和标准编号；
- 金额、比例、日期、时限、容量、型号、性能指标、RTO/RPO；
- 系统名、产品名、接口名、字段名、命令、路径、日志和报错；
- 建设方、承建方、监理方、运营方、招标人、投标人等责任主体；
- 招标原文、逐条应答、评审意见、验收结论和会议决定；
- “应、须、不得、可、负责、承担”等规范性或责任性表达；
- 用户明确要求原样保留的文字；
- 引号、代码块或明确标注为反例的教学内容。

## 判定优先级

1. 用户指定原文；
2. 正式结论、招标原文和责任条款；
3. 法规标准、参数和量化数据；
4. 技术名词、系统行为主语和命令配置；
5. 普通正文。

高优先级片段命中低优先级 AI 模式时，保持原文并说明原因。

## 改写动作

- 默认将保护片段移出改写队列。
- bounded 模式建议删除整句时，只要句中包含保护片段，就不得进入删除清单。
- in-place 模式不删除整句；空句保留并标注人工确认。
- 用户要求修改保护片段时，先说明可能影响的事实、责任或规范性强度，再获得单独确认。
- 正式引文只可调整引文外的说明，不改引文内容。

## 确定性复核

运行：

```bash
python3 scripts/protected_diff.py before.md after.md
```

脚本检查常见文号、标准编号、金额、日期、比例、RTO/RPO、责任主体和规范性词数量。脚本只能发现客观差异，不能代替人工判断术语语义、法律适用性或隐含责任变化。
